# MORROW Prompt Library

Static, responsive website for the MORROW Founder & Compliance AI Promptbook.

## Run locally

From this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Contents
- `index.html` — site shell
- `styles.css` — responsive dark cinematic UI
- `app.js` — prompt library, search, filters, routing diagnostic, copy interactions
- `prompts.json` — all 7 full promptbook prompts
- `assets/` — MORROW logo variants
- `MORROW-Services-and-Fees.pdf` — linked professional service guide

## Deployment
Upload the folder to any static host (Netlify, Vercel static, Cloudflare Pages, GitHub Pages, S3, etc.). No build step or backend is required.

## Important
The prompts are planning tools only. Confirm professional-conduct/publicity requirements and any live legal/statutory content before public deployment.
